# Security

Instrument is a theme: YAML that sets Home Assistant's CSS variables, plus an optional
Bubble Card module of CSS. It runs no code in Home Assistant. A problem could still be
worth reporting, for example a change that loads something from outside your
Home Assistant, or a flaw in this repository's build or release setup.

## Reporting a problem

Please don't open a public issue. Report it privately instead:
[open a security advisory](https://github.com/markmalek/ha-instrument-theme/security/advisories/new).

You'll get a reply within a week. Fixes go out as a new release, and the advisory is
published once people can update.

## Supported versions

Only the latest release gets fixes.
