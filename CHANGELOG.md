# Changelog

## 1.0.6

- A new pair of README screenshots: a dashboard of only Home Assistant's built-in cards
  (weather, thermostat, tiles with their controls, media, gauges and graphs). The theme
  itself is unchanged.

## 1.0.5

- Contributor setup: issue and pull request templates, a code of conduct, a security
  policy with private reporting, and Dependabot updates. The theme itself is unchanged.

## 1.0.4

- The docs, comments and the Bubble Card module's text are in American English ("color"),
  and a test keeps them that way. The theme itself is unchanged.

## 1.0.3

- The README's screenshots and links use full URLs, so they also show on the store page
  inside Home Assistant (Marketplace / HACS). The theme itself is unchanged.

## 1.0.2

- Cleaner Settings screenshots, without the Repairs and Updates cards. The theme itself
  is unchanged.

## 1.0.1

- New README screenshots: a larger window with the sidebar collapsed on dashboards, and
  a Settings pair with the sidebar open. The theme itself is unchanged.

## 1.0.0

- First release: the Instrument theme with dark and light modes for Home Assistant,
  Bubble Card and Mushroom, and the optional `instrument` Bubble Card module.
